# Proposal: Initial Multiplayer Vertical Slice

## Why
Demonstrate end-to-end, spec-driven agentic delivery with a fictional Battleship game, including real two-player matchmaking.

## What Changes
- 3D naval scene with selectable targets
- Server-authoritative Battleship rules with generated fleets
- Automatic FIFO matchmaking and a waiting screen for the odd player
- GunDB live revision notifications, with HTTP state snapshots and authoritative commands
- Node tests for core logic and matchmaking

## Scope boundaries
No classified naval material, real ship specifications, accounts, monetization, or production deployment hardening.
